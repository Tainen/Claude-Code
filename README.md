# 株式会社勃興（VOCO）給与システム

社員一人ひとりがアカウントを持ち、基本給・RPO案件・採用イベント受注を登録すると、
給与とインセンティブが自動計算される SaaS 型の給与算出システムです。
他のメンバーの給与は本人からは見えません（オーナーのみ全員分を閲覧できます）。

## 起動方法

```bash
npm install
npm start          # http://localhost:3000
```

- データは `data/voco.sqlite` に保存されます（`DB_PATH` 環境変数で変更可能）。
- ポートは `PORT` 環境変数で変更できます。
- **最初に登録したアカウントがオーナー（管理者）になります。** 2人目以降はメンバーです。

## テスト

```bash
npm test
```

| 機能 | メンバー | オーナー |

## 給与計算ルール

### 支給サイクル

売上（イベント開催・RPO月次粗利）が発生した月の翌月にお客様から入金があり、
インセンティブは入金月より後の直近のクォーター月（**1月・4月・7月・10月**）に支給されます。

| 売上発生月 | 入金月 | インセンティブ支給月 |
|---|---|---|
| 12月・1月・2月 | 1〜3月 | 4月 |
| 3月・4月・5月 | 4〜6月 | 7月 |
| 6月・7月・8月 | 7〜9月 | 10月 |
| 9月・10月・11月 | 10〜12月 | 翌1月 |

### 基本給

最初に登録した基本給が毎月そのまま適用されます。金額が変わる場合は
新しい発効年月で追加登録すると、その月以降は新しい額が適用されます。

### 採用イベントのインセンティブ

同じ**受注月**の合計枠数に応じた段階単価です。

| 受注月内の通算枠数 | 1枠あたり |
|---|---|
| 1〜5枠目 | 20,000円 |
| 6〜10枠目 | 40,000円 |
| 11枠目以降 | 60,000円 |

例: 1ヶ月で11枠受注 → 5枠×2万 + 5枠×4万 + 1枠×6万 = **36万円**

単価の割り当ては登録順ではなく**イベント開催日が早い順**です。
例えば同じ月に「10月開催×3枠」→「4月開催×3枠」の順で受注しても、
4月開催の3枠が1〜3枠目（各2万円）、10月開催が4〜6枠目（2万・2万・4万円）になります。
各枠の支給月は、その枠のイベント開催月から上の表で決まります。

### RPO のインセンティブ

RPO案件（半年または1年契約）は、支給月の対象3ヶ月それぞれについて
「その月に稼働中の案件の月間粗利合計 × 保有額帯ごとの率」を合算して支給されます。
率はオーナーが設定画面から変更できます。

| 月間粗利の保有額帯 | 率（オーナー設定・初期値） |
|---|---|
| 〜100万円 | 3% |
| 100万円超〜150万円 | 5% |
| 150万円超〜200万円 | 7% |
| 200万円超 | 10% |

## 構成

```
src/calc.js    給与・インセンティブ計算ロジック（純粋関数）
src/db.js      SQLite スキーマ・設定値
src/auth.js    セッション認証（scrypt によるパスワードハッシュ）
src/server.js  Express API サーバー
public/        フロントエンド（SPA）
test/          計算ロジックのテスト
```

依存は Express のみで、DB は Node.js 組み込みの `node:sqlite` を使用しています（Node.js 22 以降が必要）。
