# Studio 記事デザイン調整｜Claude in Chrome 用プロンプト

用途：Studio のデザインエディタで「お役立ち記事」ページを開いた状態で、Claude in Chrome に貼る。
参考サイト：https://service.grandcentral.jp/column/sales-materials
基調色：オレンジ（見にくい・野暮ったくなる場合はオレンジ系統内で調整）。
作成：2026-09-15。

---

（ここから下をそのまま貼る）

あなたは Web デザインの実務者として、Studio で作られた株式会社VOCO のホームページ（voco.co.jp）の「お役立ち記事」ページを、読みやすく整えてください。記事の文章は一切変えません。変えるのは見た目（色・余白・装飾・フォント）だけです。

## 0. 守ること

- **公開ボタンは押さない。** 変更は「保存」まで。公開するかは私が決めます。
- 記事本文の文言・見出しの文字・並び順を変えない。段落を分ける改行の追加だけは可。
- 記事ページ（お役立ち記事の詳細テンプレートと、CMS の当該記事）以外のページは触らない。
- 作業前と作業後に、PC 幅とスマホ幅のスクリーンショットを撮って残す。
- Studio で設定できない項目があれば無理に回避せず、「できなかったこと」として最後に報告する。
- 迷ったら、装飾を足すより減らす方を選ぶ。

## 1. 参考サイトを先に読む（10分以内）

新しいタブで https://service.grandcentral.jp/column/sales-materials を開き、次を観察してメモしてください。色そのものは真似しません。「どこに、どんな種類の装飾を使って読みやすくしているか」だけを参考にします。

- H2・H3 の装飾（左の縦線、下線、背景の帯、文字サイズの差）
- 本文中の強調のしかた（太字、文字の下に引くマーカー、色文字）と、1見出しあたりの強調の数
- 段落の長さ、段落と段落の間の余白、行間
- 箇条書き・表・ポイント枠（まとめ、注意）の見た目
- 目次の有無と位置
- フォントの種類とサイズの階層（見出し／本文／注釈）

## 2. 配色ルール（オレンジ基調）

まず VOCO のトップページで使われているオレンジを確認し、それをメインカラーにしてください。取得できない場合は下の候補から始めます。

| 役割 | 候補色 | 使う場所 |
| --- | --- | --- |
| メインオレンジ | #F07B21 | H2 の左線、リンク、リストの点 |
| 濃いオレンジ | #C85F12 | 白背景に置く文字（リンク文字など）。メインオレンジ文字は白背景でコントラストが足りないので、文字にはこちら |
| 薄いオレンジ（背景） | #FFF4E8 | H2 の帯、まとめ枠、表のヘッダー行 |
| マーカー | #FFD9A8 | 強調文の下半分に引くマーカー |
| 本文文字 | #333333 | 本文 |
| 補助グレー | #6B6B6B | 注釈、画像キャプション |
| 罫線 | #E6E6E6 | 表の線、区切り線 |

判断基準：
- **オレンジを文字色に使うのはリンクだけ。** 本文や見出しの文字はダークグレー（#222 か #333）。オレンジは「線・帯・マーカー」で使う。
- 1画面に見える色は「オレンジ系2色＋グレー系」まで。それ以上増やさない。
- オレンジの面積が広くて派手に見えたら、彩度を落とす（#F07B21 → #E8833A → #D98B4E の順）か、薄い背景色を白に近づける（#FFF4E8 → #FFF9F3）。
- コントラストは、文字と背景で 4.5:1 以上を目安に。届かない組み合わせは使わない。

## 3. 要素ごとの指定（リッチテキストのスタイル設定）

Studio では、記事詳細テンプレートの「リッチテキスト」ボックスを選ぶと、H2・H3・段落・太字・リンク・リスト・表など要素ごとにスタイルを設定できます。ここを直せば全記事に同じ見た目が適用されます。まずこの方法で進め、記事本文を1つずつ触るのは 4 節の強調箇所だけにしてください。

- **本文（p）**：文字 16px、行間 1.9〜2.0、文字色 #333333、段落の下余白 1.6em 前後。本文の横幅は 680〜760px に収める（今より狭ければそのまま）。
- **H2**：文字 22〜24px、太字、文字色 #222222。左に太さ 6px のメインオレンジの縦線、背景に薄いオレンジの帯（上下 12px、左 16px の内側余白）。上の余白 56px、下 24px。**下線は付けない**（帯と左線だけ。2026-09-16 確定）。
- **見出しの中の太字（H2・H3 内の strong）には、マーカーも下線も付けない。** 見出しはそれ自体が太字なので、本文の強調スタイルが見出しに乗らないようにする。貼り付けで見出し内に太字が残っていたら、太字を解除する。
- **H3**：文字 18〜20px、太字、文字色 #222222。左に太さ 3px のメインオレンジの縦線か、下線 1px の罫線グレー。上の余白 40px、下 16px。H2 より明らかに軽く見えるようにする。
- **太字（strong）**：太字にしたうえで、文字の下半分に #FFD9A8 のマーカーを引く。Studio で「背景のグラデーション」が指定できるなら `linear-gradient(transparent 60%, #FFD9A8 60%)`。指定できない場合は、太さ 3px のオレンジ下線（#F07B21 を 50% の透明度）で代用する。
- **リンク（a）**：文字色 濃いオレンジ #C85F12、下線あり。ホバーで少し濃く。
- **箇条書き（ul/li）**：行間 1.8、項目の間 0.5em、点（マーカー）の色をメインオレンジに。番号付きも同様。
- **表（table）**：ヘッダー行は薄いオレンジの背景に太字。罫線は #E6E6E6 の 1px。セルの内側余白 12px。スマホでは表が横スクロールできるようにする（表を含むボックスに横方向のスクロールを許可）。1列目は太字。
- **引用・枠（blockquote）**：まとめや注意に使う。薄いオレンジ背景、左にメインオレンジの 4px 線、内側余白 20px、角丸 6px。
- **画像**：横幅 100%、角丸 8px、上の余白 32px、下 12px。キャプションは 13px の補助グレーで中央寄せ。
- **フォント**：見出し・本文とも Noto Sans JP（見出し 700、本文 400）を第一候補。今の設定で十分読みやすいなら変えない。明朝体や装飾フォントは使わない。

## 4. 対象記事の本文で行うこと

CMS の「お役立ち記事」から、タイトルが「採用イベントの費用対効果はどう測ればいい？｜「話せた学生1人あたりの接触単価」で判断する」の記事を開いてください。

- 各 H2 の直下にある結論の一文を太字にする（マーカーが付く）。強調は **1つの見出しにつき 1〜2か所まで**。増やすと効かなくなる。
- 4行を超える段落があれば、文の区切りで2段落に分ける。文言は変えない。
- 「まとめ」の箇条書きは、引用（枠）の中に入れるか、リストの見た目が整っていればそのまま。
- 表がスマホ幅で崩れていないか確認する。
- 他の記事には手を入れない（テンプレートのスタイル変更で自動的に反映される分だけでよい）。

## 5. 確認と報告

1. PC 幅（1280px）とスマホ幅（390px）でプレビューし、作業前後のスクリーンショットを撮る。
2. 次の項目を自分で確認する：オレンジの文字が白背景に載っていないか／1画面の色数が 3 系統以内か／H2 と H3 の差が一目でわかるか／表が横に切れていないか／マーカーが文字にかぶって読みにくくなっていないか。
3. 最後に、次の形式で報告する。
   - 変更した要素と設定値（例：H2 左線 6px #F07B21、背景 #FFF4E8、上余白 56px）
   - 参考サイトから取り入れた点と、あえて取り入れなかった点
   - Studio の制約でできなかったこと（代替案があれば併記）
   - 公開前に私が見るべき箇所（スクリーンショットの該当位置）

## 修正用の短いプロンプト（H2 の下線を外す。Studio のデザインエディタで記事詳細ページを開いて貼る）

```text
お役立ち記事の詳細ページで、H2 見出しに付いているオレンジの下線を外してください。H2 は「左の縦線 6px ＋ 薄いオレンジの帯」だけにします（参考：「結論：費用対効果は…」の見出しの見た目）。

確認と修正の手順：
1. リッチテキストの要素スタイルで H2 を選び、下線（border-bottom / text-decoration）が設定されていれば外す。
2. 本文の太字（strong）に下線やマーカーを設定している場合、見出し（H2・H3）の中の太字には効かないようにする。Studio で要素の入れ子指定ができない場合は、CMS の記事本文で H2・H3 の中の太字を解除する（見出しはそれ自体が太字なので見た目は変わらない）。
3. 「学生は「知らない会社」を避けているのではない」の見出しで下線が消えたこと、「結論：費用対効果は…」と同じ見た目になったことを、PC 幅とスマホ幅で確認する。
4. 公開はしない。保存まで。変更した設定値と、手で太字を解除した記事名を報告する。
```

## 補足（堀本さん向け・貼らない）

- リッチテキストの要素スタイルはテンプレート単位で全記事に効く。記事ごとに色を変える運用にはしない。
- Personal プランではカスタム CSS が使えないため、マーカーのグラデーション指定ができない可能性がある。その場合は太い半透明の下線で代用する。
- 公開は堀本さんが行う。Claude in Chrome には「保存」までしか許可しない。
- 参考サイトと VOCO サイトは Claude Code の実行環境からは閲覧できない（ネットワーク制限）。デザインの観察は Chrome 側で行う前提。
