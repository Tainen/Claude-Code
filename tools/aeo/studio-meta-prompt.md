作成：2026-11-06。

## タイトルの付け方（この方針で設定する）

- **CMS記事ページ（お役立ち記事）**：記事タイトルのフィールドをそのまま使う。サフィックス（「｜株式会社VOCO」など）は付けない。記事タイトルが30字を超えるものが多く、サフィックスを足すと検索結果で社名まで表示されずに切れるため。
- **CMSニュースページ**：同じくニュースタイトルのフィールドをそのまま使う。
- **静的ページ**：「ページ名｜株式会社VOCO」。例「会社概要｜株式会社VOCO」。
- **TOPページ**：「株式会社VOCO」。

## 0. 守ること

- **ページの内容・デザイン・CMSの記事本文は一切編集しない。** 触るのはメタ情報（SEO）の設定だけです。
- **フォームの送信はしない。**
- **CMSのフィールドを新規追加しない。** 必要なフィールドが無い場合は、無いことを報告して止まってください。
- 画面が説明と違う、設定項目が見つからない、意味が分からない選択肢がある——このいずれかに当たったら、**その場で止めて、スクリーンショットと項目名をそのまま報告**してください。自分で判断して進めないでください。
- 操作の回避策を試すのは2回まで。

## 1. 先に構成を調べて報告できる状態にする

設定に入る前に、次を調べて書き出してください。

1. **サイト全体の設定**：サイトタイトル、デフォルトのディスクリプション、デフォルトのOGP画像に相当する項目がどこにあり、それぞれ現在どうなっているか（未入力か、入力済みか）。
2. **CMSの「記事」モデルのフィールド一覧**：フィールド名と型をすべて挙げる。特に、記事タイトル／ディスクリプション（説明文・SEO説明）／カバー画像に当たるフィールドがあるかを明記する。
3. **CMSの「ニュース」モデルのフィールド一覧**：同上。
4. **CMS動的ページのSEO設定**：`/case/consulting/:slug` と `/news/:slug` のページ設定に、title・description・OGP画像の項目があるか。**それらに CMS のフィールドを差し込める（バインドできる）仕組みがあるか。** あれば、その操作方法（項目の横のアイコンなど）を書く。
5. 静的ページ（`/` `/company` `/member` `/case` `/download` `/service/consulting` `/service/presentation` `/sustainability-dark`）のページ設定に、title・description の項目があるか。

**4 でCMSフィールドをバインドできる仕組みが見つからない場合は、ここで止めて報告してください。** 記事21本を手入力するかどうかは別途判断します。

## 2. サイト全体の設定

1. サイトタイトルに「株式会社VOCO」を入力する。
2. デフォルトのディスクリプション欄があれば、次を入力する。
   `新卒採用のコンサルティング、採用代行（RPO）、大学の部活動と連携した採用イベントで、中小企業の新卒採用を支援する株式会社VOCOの公式サイトです。`
3. デフォルトのOGP画像の欄があり、画像が未設定であれば、**空のままにして報告**してください（画像は別途用意します）。

## 3. CMS動的ページの設定（ここが本題）

### 3-1. お役立ち記事（`/case/consulting/:slug`）

1. このページのSEO設定を開く。
2. **title に、CMSの「記事タイトル」フィールドをバインドする。** サフィックスは付けず、記事タイトルだけにする。
3. **description に、CMSのディスクリプション（説明文・SEO説明）フィールドをバインドする。** 該当するフィールドが無い場合は、description は空のままにして、その旨を報告する。
4. **OGP画像に、CMSのカバー画像フィールドをバインドする。** 該当フィールドが無い場合は空のままにして報告する。

### 3-2. ニュース（`/news/:slug`）

3-1 と同じ要領で、ニュースのタイトル・ディスクリプション・カバー画像のフィールドをバインドする。

## 4. 静的ページの設定

次のページの title を「ページ名｜株式会社VOCO」の形で設定する。descriptionの欄があれば、そのページの内容に合う1文を入れる（既存のページ本文から取る。新しい文章を作らない）。

| ページ | title |
|---|---|
| `/`（TOP） | 株式会社VOCO |
| `/company` | 会社概要｜株式会社VOCO |
| `/member` | メンバー紹介｜株式会社VOCO |
| `/case` | 支援事例｜株式会社VOCO |
| `/service/consulting` | 採用コンサルティング｜株式会社VOCO |
| `/service/presentation` | プレゼン・説明会支援｜株式会社VOCO |
| `/download` | お役立ち記事｜株式会社VOCO |
| `/sustainability-dark` | サステナビリティ｜株式会社VOCO |

※ ページ名が上の表と違う場合は、実際のページ名に合わせてください。合わせた場合は報告に書いてください。

## 5. 公開する

1. 設定を保存する。
2. **「サイト更新」を実行**する。実行前に「更新差分を確認する」を開き、**メタ情報以外の変更が含まれていないか**を確認する。ページ内容の変更が混ざっていたら、**実行せずに報告**してください。
3. 反映に5分程度かかるため、5分以上待つ。

## 6. 確認

次の3つのURLをブラウザで開き、**タブに表示されるタイトル**を確認して報告してください。

- https://voco.co.jp/ → 「株式会社VOCO」
- https://voco.co.jp/case/consulting/oyakudachi_01 → 「イベント出展は本当に得？…」で始まる記事タイトル
- https://voco.co.jp/news/news20260929 → 「北海学園大学女子ラクロス部とスポンサー契約を締結」

## 7. 報告

1. **設定が完了したかどうか**（完了／途中で中断／できなかった）
2. 1 で調べた構成（サイト全体の設定項目／記事モデルのフィールド一覧／ニュースモデルのフィールド一覧／動的ページでバインドできたか／静的ページの設定項目の有無）
3. **バインドできなかった項目**と、その理由（該当フィールドが無い／バインド機能が無い、など）
4. 「サイト更新」を実行したか、差分確認の結果
5. 6 で確認した3ページのタイトル（実際に表示された文字列）
6. 画面が説明と違っていた箇所
7. できなかったこと、詰まった点

## 補足（堀本さん向け・貼らない）

- 報告が来たら Claude Code 側で全ページのメタ情報を実測する。公開中の記事21本・ニュース3本すべてを一括で確認できる。
- **記事のサフィックスを付けない方針**にしているのは、記事タイトルが長いため。例「イベント出展は本当に得？「話せた学生1人あたりのコスト」で測る正しいROI」は38字あり、「｜株式会社VOCO」を足すと検索結果で確実に切れる。社名は h1 の外側（ヘッダー）とドメインで伝わる。方針を変える場合はこのプロンプトの表を書き換える。
- **CMSにディスクリプション用のフィールドが無い可能性がある。** その場合、選択肢は2つ。①フィールドを追加して21本分を入力する（各記事の正本 `content/articles/out/No.xxx_article.html` の先頭コメントにメタディスクリプションを用意済み）。②description は空のままにする。title さえ入れば検索結果の見え方は大きく改善するので、まず title を優先してよい。
- OGP画像も同様。カバー画像フィールドが無ければ、当面は空で問題ない。
