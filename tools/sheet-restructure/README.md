# 商談管理シート 構造変換ツール

営業管理スプレッドシートの「商談管理」シートを、
**1企業1行（サービスを右に横並び）** から **1サービス1行（縦持ち）** に変換します。

## 変換前後のイメージ

変換前（1企業 = 1行、列 A〜CP）

```
A〜R   企業・商談の共通情報
S〜Z   1つ目のサービス            AI〜AL  ← 2つ目のサービスのネクスト情報
AA〜AH 2つ目のサービス            AU〜AX  ← 3つ目 〃
AM〜AT 3つ目のサービス            BG〜BJ  ← 4つ目 〃
AY〜BF 4つ目のサービス            BS〜BV  ← 5つ目 〃
BK〜BR 5つ目のサービス            CM〜CP  ← 6つ目 〃
BW〜CD 6つ目のサービス
CE〜CL 7つ目のサービス
```

変換後（1サービス = 1行、列 A〜AE）

| 列 | 内容 | 区分 |
| --- | --- | --- |
| A〜R | `#` / 商談獲得者 / 企業名 / 部門名 / 役職 / 担当業務 / 姓 / 名 / 電話番号 / メール / 商談タイプ / 商談獲得日 / 商談予定日 / アポ背景 / ネクスト期日 / NA / 担当者メモ / 文字起こし | 共通（同一企業の全行に複製） |
| S〜Z | 商談者 / 商談日 / 商談回数 / サービス詳細 / フェーズ / 提案金額 / 申込期日 / 失注理由 | サービス別 |
| AA | サービスNo（旧シートで何番目のブロックだったか） | 補助 |
| AB〜AE | ネクスト期日 / ネクストアクション / 担当者メモ / 文字起こし（サービス別） | 補助 |

例：7サービスを提案しているプレサンスグループは、A〜R が同じ値の 7 行に分かれます。

### AA〜AE（補助列）について

旧シートには、サービス2〜6のブロックごとに
「ネクスト期日 / ネクストアクション（NA） / 担当者メモ / 文字起こし」が付いていました。
A〜R だけを共通にすると、この分（2件目以降）が失われてしまうため、
サービス別の値として AB〜AE に退避しています。
サービス1の分は共通列 O〜R と同じ内容のため、重複を避けて空にしています。

これらが不要であれば AA〜AE を削除すれば、ご指定どおり **A〜Z の 26 列**になります。

## 使い方

### 1. スプレッドシート上で直接変換する（推奨）

1. 対象スプレッドシートで **拡張機能 > Apps Script** を開く
2. `RestructureShodan.gs` の中身を貼り付けて保存
3. 関数 `restructureShodanSheet` を実行（初回は認可が必要）

元の「商談管理」シートはそのまま残し、新しいシート
**「商談管理_新フォーマット」** を作成します。何度実行しても同じ結果になります。

### 2. ローカルの xlsx を変換する

```bash
pip install openpyxl
python3 restructure_shodan.py 入力.xlsx 出力.xlsx [シート名]
```

## 変換ロジック

- C列（企業名）が空の行は無視します。
- 7つのサービスブロックのうち、8列すべてが空のブロックは行を作りません。
- サービスが1件も入力されていない企業も、情報が消えないよう1行だけ残します（S〜AE は空）。
- 日付は日付値のまま引き継ぎます。
