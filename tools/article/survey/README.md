# 学生アンケートの集計（No.046 で使用）

VOCO の部活動連携イベントの事前アンケート（スプレッドシート「【VOCOイベント】事前調査アンケート（学生）」）を集計するスクリプト。
回答データ（氏名などの個人情報を含む）はリポジトリに置かない。Drive から xlsx で書き出し、スクラッチの場所で実行する。

1. `python3.13 -I tools/article/survey/1_load.py <survey.xlsx> <all.pkl>` … 全シートを読み、設問名の違いをそろえて1つの表にする（「シート2」は別形式の重複なので除外）
2. `python3.13 -I tools/article/survey/2_prep.py <all.pkl> <clean.pkl>` … タイムスタンプのない集計行・テスト回答を除き、同じ氏名は最新の1件だけ残す。学年、出身・希望勤務地の都道府県、大学の所在地域、地元志向（第1希望＝出身都道府県）を作る
3. `python3.13 -I tools/article/survey/3_analyze.py <clean.pkl>` … 価値観・魅力を学年別・地域別に、公務員への関心、未定の割合などを集計する

注意：設問の形が異なる樽商のシートは、価値観・魅力・業界・職種の集計から除外している。pandas と openpyxl は python3.13 に入っている。
